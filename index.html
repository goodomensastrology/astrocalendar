How to subscribe

Google Calendar

Settings → Add calendar → From URL → paste the feed URL.

Apple Calendar (Mac)

File → New Calendar Subscription → paste the feed URL → set auto-refresh to "Every day".

iPhone / iPad

Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar.

Outlook

Add calendar → Subscribe from web → paste the feed URL.

Proton Calendar / Tuta

Settings → Calendars → Add calendar → Subscribe via URL.

Good to know

  • Event times are in UTC — your calendar app automatically shows them in your local time zone.
  • The feed regenerates daily, so new transits appear on their own.
  • Your calendar app controls how often it checks for updates (Google can take up to ~24 hours).
